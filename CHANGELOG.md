# Changelog

## [Unreleased]

### Исправлено (Фаза 11 — Баг-фиксы)

- **B1** — Многострочные библейские ссылки теперь корректно тапаются (`BibleEditText`).
  Touch-handler переработан: вместо проверки только первой строки спана используется
  трёхветочная логика (первая строка / последняя строка / средние строки).

- **B2** — Устранено мигание пустой заметки в списке при немедленном выходе из редактора.
  SQL-запросы `observeRootNotes` и `observeNotesInFolder` теперь фильтруют заметки
  с пустым заголовком и пустым контентом (`NoteDao`).

- **B3** — Восстановлен фокус и позиция курсора в редакторе после смены ориентации экрана.
  Добавлен `CursorTrackingEditText` (подкласс `EditText` с `onSelectionChanged`),
  позиция курсора сохраняется через `rememberSaveable` в `NoteEditorScreen`.

- **B4** — Режим выбора теперь доступен при любом количестве заметок (было: только при 2+).
  Условие изменено с `rootNotes.size > 1` на `rootNotes.isNotEmpty()` (`NotesListScreen`).

- **B5** — Системная кнопка «Назад» в пикере книг Библии теперь закрывает пикер,
  а не уходит с экрана Библии. Добавлен `BackHandler` в `BibleReaderScreen`.

- **B6** — Системная кнопка «Назад» на экране выбора переводов (онбординг) больше не
  возвращает на слайды онбординга. Навигация изменена на `popUpTo("onboarding")
  { inclusive = true }` в `MainActivity`.
